Revision compaction

Compaction keeps the project's history small. For changes older than the age you set, it keeps every released version, the versions of builds still on disk, the versions pinned by scheduled releases, and the state of each page, record and file at the end of every day (UTC). It drops the exact in-between states of those days: you can still travel to such a revision, but you see the state at the end of its day. Removed states can't be brought back.
