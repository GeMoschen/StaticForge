# M34.4 — UI: tabs, split view and one save

## Context

`templates.component`, `dataset-schema-editor.component`, `global-set-detail.component`; new shared `sf-tabs`,
`sf-cdl-sections-editor`, `cdl-sections.ts`. User decisions 3–6.

## Goals

- `sf-tabs`: ARIA tab list with roving `tabindex`, arrow/Home/End keys, error badge, unsaved dot, note.
- `sf-cdl-sections-editor`: one code editor per section kept alive while hidden (own undo history), per-tab
  diagnostics with jump-to-position, projected per-tab content (inherited editors/bodies).
- Templates: CDL panel and channel panel side by side; one editor per channel; add/remove channel staged (removal
  undoable); one *Save template* sending sections and `channelSources`; dirty tracking gates Save; a rejected save opens
  the failing tabs; `Ctrl/Cmd+S`; the reload after a save keeps edits typed meanwhile.
- Datasets: Content | Rules beside the record template tabs; one editor per channel.
- Global sets: one Save (header) for values and schema; Content | Rules on the Schema tab.
- The code editor updates its accessible name when its label changes.
